# Paradox Community Site

Sito pubblico di **Paradox Project [Beta]**, pubblicato gratuitamente con GitHub Pages.

## Pubblicazione

GitHub Pages pubblica la cartella `docs` del branch `main`.

Il sito è completamente statico: non richiede Linux, No-IP, Node.js, Caddy o porte aperte sul router. I conteggi Discord vengono letti direttamente dall'invito pubblico della community.

## Trasparenza e accessibilità

Il sito non usa analytics, advertising, form, newsletter o cookie di profilazione. Include informative dedicate per privacy, termini, cookie e accessibilità, oltre a skip link, focus visibile, menu da tastiera, testi alternativi e supporto a `prefers-reduced-motion`.

## Limite del bot

GitHub Pages non esegue un backend, quindi non può ricevere direttamente gli aggiornamenti del bot Paradox o mostrare in tempo reale i giocatori SCP:SL. Per questa funzione servirà in futuro un piccolo servizio esterno oppure un aggiornamento periodico tramite GitHub Actions.
